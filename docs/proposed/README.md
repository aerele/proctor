# docs/proposed/ — design proposals & specs (not yet built)

Fleshed-out designs for `ROADMAP.md` / `BACKLOG.md` items live here. The
convention (see [`AGENTS.md`](../../AGENTS.md) → "THE ROADMAP RULE"): a non-trivial
planned item gets a code-grounded spec in this directory, and its roadmap/backlog
entry **links to it** — "we already have a proposal, start from there." When the
work ships, the feature gets reference docs under `docs/features/` and the proposal
is marked Implemented or retired.

## Index
- `bulk-problem-template-io.md` — **BANK-1** (v1.1) bulk export/import of problems +
  templates (multi-select, dedup, cross-instance versioning). *[in progress]*
- `eval-rule-registry.md` — **EVAL-1** (v1.1) data-driven eval rule registry. *[in progress]*
- `alert-feedback-suppression.md` — **ALERT-1** (v1.1) candidate alert feedback +
  per-user/test alert suppression. *[in progress]*

Pre-convention design history lives under `docs/design-history/specs/` and
`docs/design-history/plans/` — link those directly from the roadmap where relevant.
