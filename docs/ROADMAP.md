# Aerele Proctor — Roadmap

This file previously held a pre-build requirements-capture dump (June 2026) that
described features as "not yet designed." Those have since shipped — persistent
sessions, single-session-per-username, live alerts + remote actions, the
invigilator portal, and live submission evaluation are all in the product today.

For what exists now, see the top-level [`README.md`](../README.md) and the
feature docs under [`docs/features/`](features/). Planned work and open questions
are tracked as GitHub issues on this repository.
